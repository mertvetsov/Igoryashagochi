# Игоряшгочи

Тамагочи про Игоряшу для GeekMagic SmallTV (экран 240×240).
Сейчас здесь — прототип анимаций на PNG-спрайтшитах: персонаж сам живёт в комнате
(стоит, чешется, ходит, просит хинкал, гадит), можно включать действия вручную и листать покадрово.

**Посмотреть:** https://mertvetsov.github.io/Igoryashagochi/

## Запуск локально

```bash
python3 -m http.server 8240
```

Открыть http://localhost:8240. Пробел — пауза, → — следующий кадр.

## Структура

| Путь | Что там |
| --- | --- |
| `source/` | Исходные сгенерированные листы (1254×1254, с мусором и красной каймой), паспорт персонажа, фон комнаты |
| `tools/build_sprites.py` | Чистит исходники и режет в игровые листы |
| `assets/sprites/` | Готовые спрайтшиты: ячейка 240×240, персонаж 140 px, ноги на y = 199 |
| `js/animations.js` | Данные анимаций: последовательности кадров, длительности, траектория ходьбы, реплики |
| `js/app.js` | Движок и UI песочницы |

## Пересборка спрайтов

```bash
python3 -m venv .venv && .venv/bin/pip install pillow numpy scipy
.venv/bin/python tools/build_sprites.py
```

Скрипт для каждого листа: отрезает полупрозрачный шум, снимает красную кайму по контуру,
выкидывает мелкие обрывки, масштабирует так, чтобы стоячий кадр был 140 px,
ставит ноги на линию пола и центрирует по центру масс тела.
